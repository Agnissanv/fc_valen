# FC Valen
Site statique (HTML/CSS/JS). Les pages sont générées par `node _build/build.js` : modifiez les données et textes dans `_build/build.js`, puis relancez la commande.
- `styles/style.css`, `scriptes/main.js` : design et interactions
- `asset/web/` : images optimisées (WebP) ; polices auto-hébergées dans `styles/fonts/`
- Les contenus (résultats, joueurs, article, RNA/SIRET des mentions légales) sont fictifs : à remplacer.
